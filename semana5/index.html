Dockerfile (App Backend) 
FROM python:3.9-slim
WORKDIR /app

# Instalar dependencias
COPY requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt

# Copiar el código fuente
COPY . .

EXPOSE 5000
CMD ["gunicorn", "--bind", "0.0.0.0:5000", "wsgi:app"]

¿Por qué usar Contenedores?

  • Portabilidad absoluta: El sistema funciona igual en desarrollo, pruebas y producción ("Elimina el 'en mi máquina funciona'").
  • Eficiencia: A diferencia de las Máquinas Virtuales, no duplican el SO invitado, ahorrando gigabytes de RAM.
  • Despliegue ágil: Inician en milisegundos, permitiendo auto-escalado inmediato.
