Caso Práctico: Implementación de Sistema E-Commerce

Desarrollo, despliegue y gestión de estándares para una plataforma web empresarial usando metodologías ágiles (Scrum) y contenedores.

Descripción del Proyecto

La empresa "TechStore" requiere un nuevo sistema web de comercio electrónico (E-commerce) para gestionar sus ventas, inventario y la fidelización de sus clientes.

El equipo de TI ha decidido utilizar la metodología Scrum para la gestión del proyecto, garantizando entregas incrementales y adaptación constante. Además, para asegurar la portabilidad y escalabilidad, el sistema se desplegará utilizando Docker mediante un pipeline CI/CD, aplicando métricas de calidad y seguridad respaldadas por las normas ISO.

Objetivo del caso: Elaborar los artefactos de Scrum para el sistema web, plantear el flujo de despliegue mediante contenedores y relacionar las normas ISO para la mejora continua.

Flujo de Despliegue con Docker y CI/CD

La aplicación utiliza arquitectura basada en contenedores, evitando los problemas de "en mi máquina sí funciona". Se reemplaza la Máquina Virtual tradicional por contenedores ligeros que comparten el Kernel del Host (Docker Engine).

Pipeline CI/CD (Integración y Despliegue Continuo)
  1. Code & Commit: Desarrollador hace `git push` a GitHub.
  2. Build: GitHub Actions compila el código y construye la imagen de Docker.
  3. Test: Se ejecutan pruebas automatizadas (JUnit, Jest).
  4. Release: La imagen se sube a un Docker Registry (Docker Hub).
  5. Deploy: El servidor de producción hace `docker pull` y reinicia el contenedor.
Ejemplo de Dockerfile (Backend Flask)
FROM python:3.9-slim
WORKDIR /app
COPY requirements.txt .
RUN pip install -r requirements.txt
COPY . .
EXPOSE 5000
CMD ["python", "app.py"]

Implementación de Estándares ISO en el Proyecto

Para asegurar que nuestro sistema web de E-commerce cumpla con estándares de clase mundial, la organización integra las siguientes normas en su ciclo de vida:

ISO 27001
Seguridad de la Información

Se implementan controles estrictos como encriptación de contraseñas de usuarios, auditorías contra inyecciones SQL y un certificado SSL obligatorio para todas las transacciones (mitigando ataques Man-in-the-Middle y brechas de datos).

ISO 9001:2015
Gestión de Calidad

Los procesos de desarrollo Scrum y el pipeline CI/CD están estandarizados y documentados. Existe un proceso formal de revisión y retroalimentación tras cada despliegue para asegurar la mejora continua.

ISO/IEC 25010
Calidad de Software

Se establecen métricas de rendimiento y usabilidad. Los contenedores de Docker permiten alta escalabilidad (Eficiencia de desempeño), y las pruebas automatizadas garantizan fiabilidad antes del pase a producción.
