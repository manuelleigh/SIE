Dockerfile (App Backend) 
FROM python:3.9-slim
WORKDIR /app

# Instalar dependencias
COPY requirements.txt .
RUN pip install -r requirements.txt

COPY . .
EXPOSE 5000
CMD ["gunicorn", "wsgi:app"]

¿Por qué usar Contenedores?

  • Portabilidad absoluta: El sistema funciona igual en todos los entornos.
  • Eficiencia: No duplican el SO invitado, ahorrando RAM.
  • Despliegue ágil: Inician en milisegundos (Auto-escalado).
